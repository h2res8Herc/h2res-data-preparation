H2RES Data Preparation

Windows transfer package, 4 November 2026.

  1. Use 64-bit Python with Tcl/Tk: Python 3.12 is recommended for offline setup; existing compatible Anaconda/Python 3.10+ can install dependencies online.
  2. Run SETUP_WINDOWS.bat. It discovers installed interpreters and creates the local project environment.
  3. After setup succeeds, open START_DATA_PREPARATION.bat. It always uses the completed local environment.
