# Custom-zone CSV examples

Open [the custom-zone guide](../CUSTOM_ZONES.html) for the complete format, membership choices and support limits.

- `HR_SI_IT_complete.csv`: supported full-coverage mapping format; includes IT_REST as a modeled zone.
- `HR_SI_north_IT_PARTIAL_NOT_SUPPORTED.csv`: requested land coverage, requiring partial-country support before use.
- `HR_offshore_DESIGN_ONLY.csv`: proposed independent offshore definition; not a currently supported input schema.

These are input examples. They contain no generated sector data, API tokens or country output bundle.
